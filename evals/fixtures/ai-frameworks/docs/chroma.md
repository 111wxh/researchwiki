# Chroma：轻量嵌入式向量库

Chroma 是面向开发者本地工作流的嵌入式向量数据库，pip 安装即用，提供 Python 与 JavaScript 双客户端，适合原型验证与中小规模知识库。

持久化只需在创建客户端时传入 `persist_directory` 参数，数据落盘为本地目录，重启后 collection 与向量自动恢复；不传该参数则运行在纯内存模式，进程退出数据即失。

距离度量在 collection 级别配置：`hnsw:space` 元数据默认 l2（欧氏距离），可切换 cosine 与 ip（内积）；度量在建库时确定，之后不可更改，换度量必须重建 collection。

多租户能力自 0.5.0 起引入（2024-11-30 发布）：tenant 与 database 两级命名空间隔离数据，多团队共用实例时互不可见；旧版本只有 collection 一级，隔离靠约定。

当前版本 0.6.3，发布于 2025-02-10，主要改进是重写了段合并策略，批量写入吞吐提升约 30%。

规模边界：单实例百万级向量内体验良好；更大规模或需要 GPU 索引时，参考 Milvus 篇的分布式方案。
