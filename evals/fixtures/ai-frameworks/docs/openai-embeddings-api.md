# OpenAI Embeddings API：文本向量化

Embeddings API 把文本映射为定长向量，用于语义检索、聚类与分类。旗舰模型 text-embedding-3-large 默认输出 3072 维向量，输入上限 8191 tokens，超出需自行切分。

维度弹性是该系列的招牌：请求时传 `dimensions` 参数即可把输出降到目标维度，最低 256 维；服务端采用 Matryoshka（套娃）训练方式截断，短维度仍保留大部分检索质量。维度直接决定向量库的存储成本，3072 维下 100 万条文本约占 12 GB 内存。

定价按输入 token 计，text-embedding-3-large 为每百万 tokens 0.13 美元；走批处理接口减半。

最佳实践：查询与文档必须使用同一模型、同一维度，否则空间不可比；中文场景建议先做规范化（去多余空白、全角转半角）再向量化；检索质量的横向对比应在固定基准上进行（参见嵌入模型选型篇）。

`encoding_format` 参数支持 float 与 base64 两种返回格式，base64 编码可省约四分之一的传输体积，批量任务建议开启。
