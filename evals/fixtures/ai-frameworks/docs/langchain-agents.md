# langchain-agents：智能体执行循环

langchain-agents 提供基于工具调用的智能体运行时，核心入口是 AgentExecutor。它把"模型决策 → 调用工具 → 拿回观察 → 再决策"的 ReAct 循环封装成一个 Runnable，业务代码只需要提供工具列表与提示词模板。

AgentExecutor 有几个关键参数：`max_iterations` 控制单次任务最多迭代多少轮，默认 15，超过即终止并给出超限提示，防止智能体陷入死循环空烧费用；`return_intermediate_steps=True` 会在返回结果里附上每一轮的中间步骤，便于调试与回放；`handle_parsing_errors=True` 则让执行器在模型输出无法解析时，把解析错误自动回喂给模型重试。

工具方面，每个工具由名称、描述与实现函数三部分组成。描述写得是否清晰直接决定模型选工具的准确率，官方把"写好工具描述"列为智能体调优的第一优先级；工具调用结果作为观察值进入下一轮上下文，直到模型输出最终答案。

与 LangGraph 的关系：单智能体、线性工具循环用 AgentExecutor 足够；需要多智能体协作、人工审批节点或复杂状态转移时，应迁移到 LangGraph 的状态图模型（参见 langgraph 篇）。两者共享工具定义与消息类型，迁移的主要工作量在循环逻辑改写为图结构。
