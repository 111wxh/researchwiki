# LangChain 版本史

LangChain 自 2022 年开源以来经历了一次彻底的架构拆分与三次大版本演进，本篇按时间线梳理主干节点（日期以官方发布公告为准）。

0.1.0 于 2023-10-18 发布，是首个被标记为稳定的版本，链、智能体、记忆三件套在此版定型。0.2.0 于 2024-05-20 发布，完成最重要的架构动作：把与模型厂商无关的核心抽象拆成独立的 langchain-core 包，主包只保留集成与上层封装，第三方集成的依赖冲突问题由此明显缓解。

0.3.0 于 2024-09-15 发布，全面切换到 Pydantic v2，消息与工具的序列化性能明显提升，同时统一了流式事件的格式。0.3 线的最后一个补丁版本是 0.3.15，发布于 2025-03-12；此后版本线进入 0.4，0.4 线的版本动态与维护者信息以 langchain-core 文档（含修订版）为准，本篇不再追记。

选型建议：新项目直接使用最新稳定线；从 0.1 升级的旧项目需要先跨过 0.2 的包拆分，官方提供迁移脚本与兼容层，建议分两步升级而不是直接跳版本。
