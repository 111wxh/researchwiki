# 记忆系统设计综述

LLM 应用的记忆分两层：会话内短期记忆与会话外长期记忆。设计中最常见的错误是把两者混为一谈，用同一个机制应付两种需求。

短期记忆即上下文窗口内的对话历史，核心问题是裁剪策略。经验区间是保留最近 8–16 轮对话：窗口过短会丢任务上下文，过长则稀释模型注意力且费用线性上涨。各框架默认值普遍偏保守，例如 LangChain 的 ConversationBufferWindowMemory 默认 k=5，生产环境通常需要调大。

摘要式记忆把历史压成一段摘要，代价是细节丢失——日期、数字、人名这类实体最容易被摘要吞掉，关键实体应另存结构化槽位，与摘要并行维护。

长期记忆跨会话存在，主流方案是向量记忆：把历史片段向量化入库，新消息到来时按语义相似度检索相关片段注入上下文。两个要点：写入要有筛选，不是所有对话都值得记；读出要有去重与时效衰减，避免陈旧记忆压过新事实。

评测口径：记忆系统的收益必须在多轮、跨会话的题集上才能测出，单轮问答测不出差异；这也是本评测支线设置多跳与时效题型的原因。
