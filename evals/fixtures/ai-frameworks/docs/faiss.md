# FAISS：向量检索基石库

FAISS 是 Meta 开源的高密度向量相似度检索库，以 C++ 为核心、Python 绑定开箱即用，是学术界与工业界最常用的离线检索基线。

索引分三档：IndexFlatL2 做精确检索，穷举全部向量的 L2 距离，结果精确但规模大后变慢；IVF 系先聚类分桶，查询时只探测 `nprobe` 个桶，该参数默认 1，调大可提升召回但查询变慢；HNSW 是多层图索引，用内存换速度，低延迟场景首选。

官方基线测试（FixtureVec-Bench，受控口径）：100 万条 768 维向量、HNSW 索引、单线程查询 P99 延迟 4.8 ms，recall@10 达 0.98；IndexFlatL2 在同等规模下 P99 约 42 ms。

FAISS 本体不做服务化：索引写盘用 `write_index`、加载用 `read_index`，进程内检索；过滤、多租户、主从复制等工程能力需要外部封装。当前版本 1.9.0，发布于 2025-01-22。

选位结论：百万级以下、静态数据用 FAISS 足够；需要在线更新、分布式与 GPU 加速时，参考 Milvus 篇或 Chroma 篇的对应方案。
